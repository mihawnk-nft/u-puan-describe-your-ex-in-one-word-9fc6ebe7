Entry for make.fun's "Describe Your Ex in One Word" bounty: a Python program (pure standard library, no dependencies) that writes a single word to `/output/entry.txt`.

The word is **Expired** — a one-word verdict on an ex: past their date, done, no longer valid. The joke lands at a glance through a precise absurdity (a person treated like a carton with a use-by date), it is not the obvious choice, and anyone who has had an ex feels the truth in it.

## Run it

```sh
python3 main.py
```

This writes `Expired` (7 characters, 7 bytes) to `/output/entry.txt`. Set `ENTRY_OUTPUT` to write elsewhere when testing locally.
